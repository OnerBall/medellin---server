# Medellin — оптовый каталог в Telegram

Mini App каталог + бот. Товары **заливаются сами из Telegram-канала**:
вы публикуете пост (фото + описание + цена + хэштег) — бот добавляет товар в каталог.
Заказы из каталога приходят вам в бот с кнопками статуса и кнопкой WhatsApp клиента.

## Как это работает

- **Новый пост в канале** → бот разбирает текст: название (первая строка), цена (`650тг`, `4 500 ₸`),
  упаковка (`В упаковке: 12шт`), размеры (`Размеры: M L`), страна (`Производство: 🇨🇳`), категория — по хэштегу.
- **Альбом** (несколько фото в одном посте) → один товар со всеми фото.
- **Старые товары** → выделите посты в канале и перешлите боту. Дублей не будет.
- **Пост изменили** → товар в каталоге обновится.
- После каждого товара бот присылает карточку с кнопками: 📂 Категория, 💰 Цена, 📦 Упаковка,
  🙈 Скрыть, ⛔ Нет в наличии, 🗑 Удалить.
- Если бот не нашёл цену или категорию — товар скрыт, пока вы не нажмёте кнопку и не поправите.

## Деплой на Railway

1. **New Project → Deploy from GitHub repo** → `medellin---server`.
2. **Settings → Networking → Generate Domain**.
3. **+ New → Volume**, подключить к сервису, путь `/data`.
4. **Variables**:
   - `BOT_TOKEN` — токен от @BotFather
   - `ADMIN_CHAT_ID` — ваш Telegram id (@userinfobot); несколько — через запятую
   - `DB_PATH=/data/medellin.db`
   - `WHATSAPP=77022585183`
   - `CHANNEL_URL=https://t.me/<ваш канал>` (кнопка в профиле)
   - необязательно: `CHANNEL_ID` — брать посты только из этого канала (`@username` или `-100…`),
     `PACK_DEFAULT=12` — упаковка, если в посте не указана
5. После деплоя: добавьте бота **администратором канала** (право «Публикация сообщений» не нужно,
   достаточно быть админом) и напишите боту `/start`.

Вебхук и кнопка «Каталог» в меню бота настраиваются сами по домену Railway.

## Локально

```bash
npm install
BOT_TOKEN=... ADMIN_CHAT_ID=... npm start   # без домена бот работает через long polling
```
Откройте http://localhost:3000.

## Файлы

- `index.js` — сервер и запуск бота
- `bot.js` — автоимпорт из канала, карточки товаров, заказы
- `parse.js` — разбор текста поста
- `products.js` — товары (импорт, изменения, выдача)
- `categories.js` — разделы, категории, хэштеги
- `routes/catalog.js` — `/api/catalog`, фото товаров `/photo/:id/:n` (кешируются на диске)
- `routes/orders.js` — `/api/orders` (цены пересчитываются на сервере)
- `public/index.html` — сам каталог (Mini App)

## AI-ассистент (голосовой поиск)

Покупатель пишет боту или отправляет голосовое: «тёплая пижама для девочки 116».
Бот распознаёт речь, подбирает до 6 товаров из каталога и присылает альбом с фото
и кнопками — каждая открывает товар в Mini App.

- Переменная `OPENAI_API_KEY` в Railway — включает голос и умный подбор.
- Без ключа работает простой поиск по словам в тексте.
- Админ может проверить: `/find пижама для девочки` или своё голосовое боту.
- Лимит: 20 запросов в час на покупателя (`AI_LIMIT_PER_HOUR`).

### Голос внутри каталога
В строке поиска Mini App есть кнопка 🎤: нажал → говоришь → нажал ещё раз (или 15 сек) —
запись уходит на `/api/ai/voice`, товары показываются прямо в каталоге.
При вводе текста появляется кнопка «✨ Подобрать с ассистентом» (`/api/ai/find`).

## Рассылка «Новинки недели»
- Подписчики — все, кто писал боту, открывал каталог или заказывал.
- По пятницам в 12:00 (Алматы) бот присылает админу превью новинок за 7 дней
  с кнопками «✅ Отправить всем» / «⏭ Пропустить». Если новинок нет — молчит.
- `/digest` — превью вручную в любой момент. Клиент: кнопка «🔕 Не присылать», вернуть — `/news`.
- Настройки: `DIGEST_DAY` (0–6, `off`), `DIGEST_HOUR`.

## Повтор заказа, «Поделиться», аналитика
- Профиль → «Мои заказы» → **🔁 Повторить**: товары заказа (что есть в наличии) кладутся в корзину.
- Товар → кнопка «поделиться» → WhatsApp или Telegram. Ссылка `/p/<id>` даёт превью с фото
  и открывает товар в Mini App (`BOT_USERNAME` — необязательно, берётся из getMe).
- `/top` (или `/top 30`) — аналитика: что смотрят, кладут в корзину, заказывают,
  что кладут и не покупают, и **что ищут, но не находят**. События: `/api/ev`, хранятся 120 дней.

## Распродажа
- В карточке товара в боте: «🔥 В распродажу» → новая цена (`1990`) или скидка (`20%`).
  Убрать — «✖️ Убрать из распродажи». Список — `/sale`.
- В каталоге: баннер «🔥 Распродажа» на главной и в каталоге, отдельная страница,
  бейдж «−N%» и зачёркнутая старая цена. Заказ считается по цене со скидкой.
