# Medellin — backend + Mini App

Реальный сервер для каталога Medellin: та же страница (`public/index.html`),
что была прототипом, только теперь товары, заказы и курсы валют живут
в базе на сервере, а не в localStorage браузера. Плюс настоящий
Telegram-бот, который присылает уведомления о заказах с кнопками
статуса.

## Что внутри

- `index.js` — Express-сервер, отдаёт API и саму страницу
- `db.js` — SQLite (файл на диске), схема создаётся сама при первом запуске
- `bot.js` — Telegram-бот на Telegraf: шлёт заказы, ловит нажатия кнопок статуса
- `routes/catalog.js` — товары, категории, курсы валют
- `routes/orders.js` — заказы
- `auth.js` — простая защита админских ручек одним паролем
- `public/index.html` — сам Mini App (каталог + чекаут + админка)

## 1. Локальный запуск (проверить, что всё работает)

```bash
npm install
cp .env.example .env
# впишите в .env хотя бы ADMIN_SECRET, остальное можно оставить пустым —
# без BOT_TOKEN сервер просто не будет слать уведомления в Telegram
npm start
```

Откройте http://localhost:3000 — увидите каталог. «Админ» в шапке
спросит пароль — тот, что вы указали в `ADMIN_SECRET`.

## 2. Создать бота в Telegram

1. Напишите **@BotFather** → `/newbot` → придумайте имя и username
   (например `medellin_shop_bot`)
2. BotFather пришлёт токен — это `BOT_TOKEN`
3. Узнайте свой `chat_id`: напишите **@userinfobot**, он ответит вашим id —
   это `ADMIN_CHAT_ID` (куда бот будет слать уведомления о заказах)

## 3. Деплой на Railway

Тот же способ, что уже использовался для Есеп и OBL:

1. Залейте этот проект в GitHub-репозиторий
2. В Railway: **New Project → Deploy from GitHub repo**, выберите репозиторий
3. Откройте вкладку **Variables** и добавьте:
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_CHAT_ID` — ваш chat_id
   - `ADMIN_SECRET` — пароль для входа в админку в самом приложении
   - `WEBHOOK_URL` — заполните **после** первого деплоя, когда Railway
     выдаст домен (Settings → Networking → Generate Domain), например
     `https://medellin-production.up.railway.app`
4. **Важно про базу данных.** По умолчанию SQLite-файл лежит в `./data/`
   внутри контейнера — Railway пересоздаёт контейнер при каждом деплое,
   и файл может потеряться. Чтобы данные не пропадали:
   - В Railway откройте **+ New → Volume**, подключите его к сервису
     (например, путь `/data`)
   - Добавьте переменную `DB_PATH=/data/medellin.db`
5. После деплоя откройте выданный Railway домен — это и есть адрес
   вашего Mini App

## 4. Подключить Mini App к боту

В **@BotFather** → выберите вашего бота → **Bot Settings → Menu Button**
(или `/mybots` → Configure Menu Button) → укажите URL — тот самый
Railway-домен. После этого у бота в Telegram появится кнопка,
открывающая каталог как настоящий Mini App.

## 5. Диплинк на конкретный товар

Уже работает через `?product=ID` в URL. Чтобы вести из поста в
Telegram-канале сразу на товар, используйте `start_param` — ссылку вида:

```
https://t.me/medellin_shop_bot/app?startapp=p_boxers_black
```

Внутри Mini App Telegram передаёт этот параметр как
`window.Telegram.WebApp.initDataUnsafe.start_param` — на стороне
`index.html` эту точку входа нужно будет подключить рядом с уже
готовой обработкой `?product=` в функции `init()` (сейчас она читает
обычный query-параметр, этого достаточно для тестов вне Telegram,
но `start_param` — правильный канал внутри самого Telegram).

## 6. Что дальше стоит укрепить

- **Настоящая проверка администратора.** Сейчас один общий пароль
  (`ADMIN_SECRET`). Правильный способ для Mini App — проверять
  `initData`, которую подписывает сам Telegram: тогда личность
  администратора подтверждает Telegram, а не отдельный пароль.
  Меняется только `auth.js`, остального кода это не касается.
- **Фото не в базе, а в хранилище.** Сейчас фото хранятся как base64
  прямо в SQLite — просто для старта, но база разрастётся быстрее,
  чем нужно. Когда фото станет много — перенести на S3-совместимое
  хранилище (Cloudflare R2, Backblaze) и хранить в базе только ссылки.
- **Postgres вместо SQLite**, если понадобится больше одного инстанса
  сервера одновременно — SQLite это файл на диске одного контейнера.
